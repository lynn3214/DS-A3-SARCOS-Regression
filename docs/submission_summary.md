# Submission Summary

This project evaluates interpretable linear baselines for first-joint torque prediction from the 21 SARCOS kinematic features, and identifies conditions where predictions are less reliable. The source data were downloaded from a pinned public GitHub mirror; its dataset license and physical units remain unverified. Frozen blocked and seed-42 random partitions are retained, with a 25-row blocked purge. Preprocessing and fitting use training data only; Ridge alpha is selected by Validation MAE, then refit on Train plus Validation before one Test evaluation. The historical SARCOS test matrix is excluded because it substantially overlaps the source matrix.

The original Dummy, OLS, and Ridge configurations and results are preserved. Across both protocols, all 36 Validation/Test MAE, RMSE, and R² values, selected Ridge alphas, and error-slice thresholds, counts, and metrics match the retained reference exactly (maximum absolute numerical difference 0.0). Blocked evaluation supports H1: the tested Ridge baseline outperforms the training-mean Dummy. Ridge does not provide meaningful improvement over OLS in this tested setting. Descriptively, high acceleration and high absolute torque slices have higher errors; velocity-slice error is non-monotonic, with the low-velocity group having higher MAE than the highest-velocity group. Higher absolute error at large torque does not establish higher relative error.

Training-only diagnostics include residual plots, leverage and Cook-distance screening, a Breusch–Pagan regression, and a nested-subset learning curve. Post-hoc Test cases only characterize failures. Lasso and a small HistGradientBoosting search are exploratory and selected on Blocked Validation; neither changes the original Test comparison. Temporal dependence, distribution shift, limited validation representativeness, unavailable episode identifiers, and unverified redistribution terms limit the claims. Coefficients describe predictive association, not causal effects. See the Notebook, PDF, protocol, and pinned environment lock for reproduction.
